## EVS36 - Home Charging Accessibility Trends within the Clean Vehicle Rebate Project
- [Download paper](/assets/files/EVS36 - Home Charging Trends.pdf)
- [Download presentation slides](/assets/files/EVS36 - Home Charging Trends - Slides.pdf)
- [Alternative paper link](https://evs36.com/wp-content/uploads/finalpapers/FinalPaper_Alvarez_Francis.pdf)
- [Alternative slides link](https://go.energycenter.org/rs/157-ILH-029/images/EVS36_HomeChargingAccessibility.pdf)

Using Clean Vehicle Rebate Project survey data, this analysis evaluated how access to home and workplace charging differs across EV consumers in California. Findings showed that renters, multi-unit dwelling residents, and lower-income rebate participants face greater charging constraints, underscoring the importance of equitable public and workplace charging infrastructure.

## EVS36 - Building on what is already working: Describing a more nuanced understanding of rebated EV consumer groups 
- [Download paper](/assets/files/EVS36 - Understanding EV Consumers.pdf)
- [Download presentation slides](/assets/files/EVS36 - Understanding EV Consumers - Slides.pdf)
- [Alternative paper link](https://evs36.com/wp-content/uploads/finalpapers/FinalPaper_Anderson_John.pdf)
- [Alternative slides link](https://go.energycenter.org/rs/157-ILH-029/images/EVS36__Presentation_Bulding_on_what_is_already_working.pdf)

Using 2017–2020 Clean Vehicle Rebate Project survey and application data, this analysis identified six distinct EV consumer groups through latent class analysis. The report provided a more nuanced view of California EV adopters and offered insights for tailoring outreach, education, and incentive strategies to different consumer segments.
